# Plot Warp Statistics

Displays the mean warping function with a shaded +/- 2 standard
deviation confidence band.

## Usage

``` r
# S3 method for class 'warp.statistics'
plot(x, ...)
```

## Arguments

- x:

  An object of class `warp.statistics`.

- ...:

  Additional arguments (ignored).

## Value

A ggplot object.
