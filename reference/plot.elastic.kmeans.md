# Plot Elastic K-Means Result

Displays cluster mean curves with member curves in the background, one
facet per cluster.

## Usage

``` r
# S3 method for class 'elastic.kmeans'
plot(x, ...)
```

## Arguments

- x:

  An object of class `elastic.kmeans`.

- ...:

  Additional arguments (ignored).

## Value

A ggplot object.
